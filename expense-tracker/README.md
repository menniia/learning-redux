# Expense Tracker

## Overview

This project is an **Expense Tracker** application built with React and Redux. It helps users manage their budget by allowing them to track their expenses across various categories. Users can add, view, and delete transactions, as well as manage their budget for different categories.

## Features

- **Budgets**: Users can view and edit their budget for different categories (e.g., housing, food, transportation, etc.).
- **Transactions**: Users can add new transactions, view all transactions, and delete transactions.
- **Categories**: The application comes pre-configured with common categories like housing, food, transportation, etc.

## Tech Stack

- **React**: Frontend JavaScript library for building the user interface.
- **Redux Toolkit**: For managing the global state of the application (e.g., budgets, transactions).
- **UUID**: Used for generating unique transaction IDs.
